RAG (Retrieval-Augmented Generation) — это метод улучшения ответов больших языковых моделей с помощью поиска по базе знаний.
PostgreSQL — это мощная объектно-реляционная СУБД с открытым исходным кодом.
ChromaDB — это векторная база данных, специально созданная для AI-приложений.
Ollama позволяет запускать LLM локально.
